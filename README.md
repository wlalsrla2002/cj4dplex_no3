# CJ 4DPLEX Global Box Office Intelligence Dashboard

글로벌 박스오피스 트렌드와 SCREENX·4DX 콘텐츠 전략 대시보드 (데이터 기준일 2026-11-05)

## 파일 구성
| 파일 | 역할 |
|---|---|
| index.html | 웹페이지 뼈대 |
| css/style.css | 화면 스타일 |
| js/app.js | 대시보드 화면·차트·필터 동작 |
| js/data.js | 13개 시장 데이터(박스오피스·Top20 작품·특별관 지점·출처 URL) |
| js/map.js | 세계지도 경로 |
| js/react*.min.js | 화면 구성 라이브러리(React 18.3.1) |
| .nojekyll | GitHub Pages가 파일을 그대로 쓰도록 하는 설정 |

## GitHub Pages 공개
Settings → Pages → Branch `main` / `/ (root)` → Save
